# Template & GitHub Actions audit

Generated by `scripts/09-template-audit.sh`. Templates are instantiated fresh from each in-scope SDK and checked statically; workflows are linted for known GitHub Actions bug classes.

**How to read this.** A hit means "look here", not a vulnerability. Templates intentionally ship dev-only conveniences (e.g. `http://` launch profiles, `AllowedHosts: *`), and MSRC excludes samples that ignore security on purpose. A reportable template issue is an insecure default that survives into production use.
